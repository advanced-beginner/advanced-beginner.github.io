## 4. 개선 우선순위

### Phase 0: 기반 작업

1. 문서 스타일 가이드 작성
2. frontmatter에 `doc_type` 필드 추가

### Phase 1: 고영향 저비용 (1주차)

1. B등급 문서 개선 (Scala Quick Start, Kafka 기본 예제)
2. 제목 계층 정규화 (H4 → H2/H3)
3. 진행률 표시 일관화

### Phase 2: 콘텐츠 갭 (2-3주차)

1. 핵심 하우투 가이드 4개 작성
   - Kafka: Consumer Lag 해결하기
   - Elasticsearch: 검색 성능 최적화하기

   - Scala: sbt 의존성 충돌 해결하기
2. 트러블슈팅 섹션 표준화

### Phase 3: 품질 일관화 (4주차)

1. 명령형 문체 전환 (하우투 문서)
2. 환경별 탭 분리 확대

### Phase 4: 레퍼런스 파일럿 (5주차+)

1. Kafka Producer 설정 레퍼런스 작성
