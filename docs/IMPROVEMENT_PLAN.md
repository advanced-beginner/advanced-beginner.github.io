현재 Kafka, DDD, Scala만 소개됨 → **Elasticsearch, Spark 추가 필요**

```markdown
### [Apache Spark](spark/)
대규모 데이터 처리를 위한 분산 컴퓨팅 엔진. Java/Spring 개발자 관점에서 설명합니다.

**배우는 것:**
- Spark의 아키텍처와 실행 모델
- RDD, DataFrame, Dataset의 차이와 활용
- Structured Streaming으로 실시간 처리
- 성능 튜닝과 메모리 관리

### [Elasticsearch](elasticsearch/)
대용량 검색과 실시간 분석을 위한 분산 검색 엔진. 실무에서 마주치는 한계를 정면으로 다룹니다.

**배우는 것:**
- Elasticsearch의 핵심 구성요소와 역색인 원리
- Query DSL과 집계 분석
- 한글 검색 최적화와 자동완성
- 클러스터 운영과 성능 튜닝
```
