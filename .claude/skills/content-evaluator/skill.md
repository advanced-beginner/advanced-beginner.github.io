# Content Evaluator — 문서 품질 평가

## 워크플로우

### Step 0: 평가 기준 로드
반드시 EVALUATION.md를 읽어 최신 평가 기준을 확인한다.
평가표 버전과 마지막 개정 날짜를 기록한다.

### Step 1: 문서 유형 판별

frontmatter와 파일 경로를 기반으로 유형을 판별한다:

| 경로 패턴 | 유형 |
|-----------|------|
| `quick-start/` | 튜토리얼 (평가표 1) |
| `concepts/` | 설명 (평가표 4) |
| `examples/` | Examples 가이드 (EX 기준 + 주된 유형) |
| `howto/` | 하우투 가이드 (평가표 2) |
| `appendix/glossary` | 레퍼런스 (평가표 3) |
| `appendix/faq` | 레퍼런스 (평가표 3) |
| `appendix/references` | 레퍼런스 (평가표 3) |

### Step 2: Quick 평가 (스크리닝)

EVALUATION.md의 "Quick 평가표" 섹션의 20항목을 적용한다:
- 공통 Q1~Q4
- 유형별 항목 (Q5~Q8 또는 Q9~Q12 또는 Q13~Q16 또는 Q17~Q20)

각 항목에 ✓(통과) / ✗(미통과) / N/A(해당없음)을 기록한다.

**판정**:
- 모든 항목 ✓ → Pass (상세 평가 불필요)
- 1~2개 ✗ → 조건부 (해당 항목만 수정)
- 3개 이상 ✗ → Fail (상세 평가 필요)

### Step 3: 상세 평가 (정밀)

Quick 평가에서 Fail인 문서 또는 명시적 요청 시:

1. 해당 유형의 평가표 A~E 섹션을 순차 적용
2. 각 항목에 1~10점 부여 (검증 질문 활용)
3. Mermaid 있으면 M1~M4 추가 적용
4. 가중 평균으로 총점 계산
5. 등급 판정: A(8.5+), B(7.0~8.4), C(5.0~6.9), D(3.0~4.9), F(~2.9)

### Step 4: 배치 평가

여러 문서를 한번에 평가할 때:
1. 같은 도메인의 같은 유형 문서를 묶어 평가
2. 도메인 내 일관성도 함께 점검
3. 결과를 도메인별/유형별 요약표로 정리

### Step 5: 개선 제안

점수가 7점 미만인 항목에 대해:
- 현재 상태를 구체적으로 인용
- 개선 방안을 실행 가능한 수준으로 제시
- 우선순위: 가중치 높은 섹션(A, B)의 낮은 점수 항목 먼저

## 도구 사용법

- **Read**: EVALUATION.md 로드, 평가 대상 문서 읽기
- **Grep**: 특정 패턴 존재 여부 확인 (description, 시간 안내, 다음 단계 등)
- **Bash**: 통계 산출 (문서 수, 줄 수)

## 출력 규칙

- Quick 평가는 테이블 형식으로 간결하게
- 상세 평가는 섹션별 점수 + 총점 + 등급 + 개선 제안
- 배치 평가는 도메인별 평균 점수 비교표
- 항상 "평가 기준 버전"을 명시 (EVALUATION.md v2.2 등)
