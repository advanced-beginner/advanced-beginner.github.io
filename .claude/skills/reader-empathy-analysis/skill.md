# Reader Empathy Analysis — 독자 공감 분석

## 목적

EVALUATION.md는 문서의 "구조적 품질"을 측정한다. 이 스킬은 그 위에 **"독자가 실제로 이해할 수 있는가"**를 측정한다. 점수가 높아도 초보자가 막히는 문서가 있고, 점수가 낮아도 핵심은 잘 전달하는 문서가 있다. 이 차이를 포착한다.

## 6가지 이해도 장벽 프레임워크

| 코드 | 장벽 유형 | 독자가 느끼는 감정 | 탐지 신호 |
|------|----------|------------------|----------|
| AK | 암묵적 전제 지식 | "이게 뭔 말이지?" | 정의 없는 전문 용어, 설명 없는 약어 |
| CG | 개념 점프 | "갑자기 어려워졌다" | 이전 섹션과 난이도 단절, 선수 개념 미참조 |
| MW | Why 부재 | "이걸 왜 해야 하지?" | What/How만 있고 Why/When 없음 |
| AC | 추상적 설명 | "뭔가 알겠는데 와닿지 않는다" | 비유/예시/코드 없이 개념만 서술 |
| DE | 죽은 학습 경로 | "다음에 뭘 봐야 하지?" | 다음 단계 링크 없음, 관련 문서 미참조 |
| CO | 인지 과부하 | "너무 많다, 포기" | 한 섹션에 새 개념 3+, 긴 코드 블록 무설명 |

## 분석 워크플로우

### Step 1: 학습 경로 매핑

대상 도메인의 전체 문서를 weight 순서대로 나열하고 학습 경로를 시각화한다:

```
quick-start → concepts (architecture → rdd → ...) → examples → howto → appendix
```

이 순서가 "초보자가 자연스럽게 따라갈 수 있는 흐름"인지 판단한다:
- 선수 개념이 후속 문서보다 앞에 있는가?
- 이론(concepts)과 실습(examples)의 배치가 적절한가?
- 난이도 곡선이 점진적인가?

### Step 2: 문서별 장벽 스캔

각 문서를 **처음부터 끝까지 순서대로** 읽으며 장벽을 기록한다.

**스캔 체크리스트** (문서를 읽으며 자문):
- [ ] 이 문서를 처음 읽는 독자가 첫 문단을 이해할 수 있는가?
- [ ] 새 용어가 나올 때마다 정의가 제공되는가?
- [ ] 각 섹션이 "이전 섹션을 읽었다면 자연스럽게 이해되는" 흐름인가?
- [ ] "왜 이것이 중요한지" 설명이 있는가?
- [ ] 추상적 설명에 구체적 예시/비유가 동반되는가?
- [ ] 코드 블록이 있을 때 코드 전에 "무엇을 할 것인지" 설명이 있는가?
- [ ] 문서 끝에 다음 학습 단계가 안내되는가?

### Step 3: 심각도 판정

| 심각도 | 기준 | 독자 행동 예측 |
|--------|------|--------------|
| **상** | 이 장벽 때문에 학습을 중단할 수 있음 | 페이지 이탈 |
| **중** | 혼란은 느끼지만 계속 읽을 수 있음 | 불완전한 이해로 진행 |
| **하** | 약간 불편하지만 큰 영향 없음 | 약간의 스크롤 낭비 |

### Step 4: 패턴 종합

개별 장벽을 모아 도메인 차원의 패턴을 도출한다:
- 가장 빈번한 장벽 유형은?
- 특정 문서 유형(concepts vs howto)에 집중된 패턴은?
- 학습 경로 전체에 누적되는 "이해도 부채"는?

### Step 5: 산출물 저장

분석 결과를 `_workspace/`에 저장한다:
- `02_reader_barriers_by_file.md` — 문서별 장벽 목록
- `02_reader_barriers_summary.md` — 종합 패턴 분석

## 산출물 형식

### 문서별 장벽 보고서

```markdown
## [파일 경로] — 장벽 분석

**유형**: [concepts/howto/...] | **심각 장벽**: N건 | **전체 장벽**: N건

| # | 위치 (섹션) | 코드 | 심각도 | 구체적 설명 | 개선 제안 |
|---|------------|------|--------|-----------|----------|
| 1 | ## RDD 특성 | AK | 상 | "lazy evaluation" 정의 없이 사용 | 첫 등장 시 정의 추가 |
```

### 종합 패턴 보고서

```markdown
## 종합 분석

### 장벽 통계
| 유형 | 건수 | 심각 비율 |
|------|------|----------|

### 학습 경로 점수
- 순서 적절성: X/10
- 문서 간 연결: X/10
- 난이도 곡선: X/10
- 전체 완결성: X/10

### 핵심 개선 우선순위 (Top 5)
(임팩트 큰 순서)
```

## 도구 사용

- **Read**: 문서 전문 읽기 — 반드시 처음부터 읽을 것 (중간부터 읽으면 문맥을 놓침)
- **Grep**: 용어 정의 유무 확인 (`"용어".*은` 패턴), 크로스 참조 탐색
- **Glob**: 도메인 파일 구조 파악
- **Write**: 분석 결과를 `_workspace/`에 저장
